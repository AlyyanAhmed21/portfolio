# DineFlow AI portfolio integration

DineFlow AI is integrated into the existing Alyyan Ahmed portfolio as a project case-study page.

## Changes
- Added `dineflow-whatsapp-ai.html`, `dineflow-whatsapp-ai.css`, and `dineflow-whatsapp-ai.js`.
- Added the DineFlow AI project card to `index.html` Projects section.
- Added DineFlow AI to the project switcher/dropdown on the existing project detail pages.
- Reused the portfolio's `assets/dineflow/` workflow screenshots.
- Kept the DineFlow page's distinct light/WhatsApp-inspired visual treatment while linking back to the main portfolio.
- Embedded the existing YouTube demo: https://www.youtube.com/watch?v=x1JHmuqVExo

## Preview
Run `python -m http.server 8000` from this folder and open `http://localhost:8000`.

This is a local source update. It has not been deployed to the live portfolio.
